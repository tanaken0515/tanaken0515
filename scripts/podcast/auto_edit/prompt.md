# 依頼
ポッドキャストの収録後編集を自動化するRubyスクリプト `main.rb` を作ってください。ローカルPCで動けば十分です（Webアプリ化は不要）。

## 背景
- 毎週2〜3人で収録し、発話者ごとのwavファイルが残る
- 普段はLogic Proで「オーディオリージョンから無音部分を削除」を使って編集している
  （しきい値 -28dB / 無音の最低時間 0.8秒 / プリアタック 0.2秒 / ポストリリース 0.2秒）
- この一連の作業をスクリプトで再現したい

## 環境・制約
- Ruby 4.x（4系の現行の書き方で実装し、READMEにも4系前提と明記）、標準ライブラリのみ（追加gemなし）
- 音声処理は外部コマンドの ffmpeg / ffprobe を使う（インストール済み前提。起動時に存在とバージョンを確認）
- コマンドは配列渡しで実行する（`Open3` など。シェル文字列連結は避ける）
- 各発話者ファイルは同時に録音を開始しており、開始位置は揃っている前提（位置合わせは不要）
- サンプルレートやチャンネル数が入力間で異なっても動くよう、内部で揃える

## 入出力
- 入力: 発話者別のwavファイル（ `recordings/{episode_No}` 配下。2~3ファイル）＋BGMファイル（`bgm` 配下。ファイル名を指定。）
  - BGMはループ再生を前提とした音源（継ぎ目なく繰り返せるように作られている）
  - 会話の長さに合わせて繰り返し再生する。クロスフェードなど継ぎ目の加工は不要
- 出力: 編集済み音声（`output/{episode_No}.mp3`）

## 処理の順序（この順序は重要）
1. 全入力を1本にミックス（amix、normalize=0、duration=longest）
2. ミックス後の音声に対して無音区間を検出し、カットして間を詰める
3. カット後の音声を `--bgm-delay` 秒だけ遅らせ、ループ音源のBGMを `-stream_loop -1` で繰り返し、小さい音量で重ねる
   （BGMが先に流れ、数秒後に会話が始まる。BGMは会話の終了に合わせて終わる）

無音判定は必ずミックス後に行うこと（話者ごとにカットすると同期がずれるため）。

## 無音カットの仕様（Logic Pro相当）
1. `silencedetect=noise=<threshold>dB:d=<silence>` で無音区間を検出し、stderrをパースして (start, end) の配列にする
  - 末尾まで無音が続き silence_end が出ない場合は、音声の総尺（ffprobe）を end とする
2. 各無音区間について、実際に削除する範囲を `[start + post_release, end - pre_attack]` とする
  - 先頭が無音の場合は `[0, end - pre_attack]`、末尾が無音の場合は `[start + post_release, 総尺]`
  - 計算後に start >= end になる区間は削除しない
3. 削除範囲の補集合を「残す区間」として、各区間を `atrim` + `asetpts=PTS-STARTPTS` で切り出し、`concat=n=K:v=0:a=1` で連結する
  - 削除区間が多いとコマンドが長くなるため、`-filter_complex_script` でファイル渡しにする
4. その後にBGM合成（adelay → BGMの volume → amix duration=first）を行う。1回のffmpeg実行にまとめても、中間ファイルを挟んでもよい（一時ファイルは終了時に必ず削除）

## CLIオプション（デフォルト値）
- `--threshold` -28（dB）
- `--silence` 0.8（無音として扱う最低秒数）
- `--pre-attack` 0.2
- `--post-release` 0.2
- `--bgm-delay` 3.0（BGMだけが流れる秒数）
- `--bgm-volume` 0.15（BGMの音量倍率）
- `--bgm-fade` 4（会話終了時のBGMフェードアウト秒数。0なら無効）
- `--dry-run`（実行するffmpegコマンドを表示するだけで実行しない）
- `--detect-only`（検出した無音区間と削除範囲を一覧表示して終了。しきい値の調整用）

## エラー処理
- 入力ファイルやBGMが存在しない、入力ファイルがない(0個)または多すぎる(6個以上)、ffmpegが見つからない場合は、分かりやすいメッセージで終了
- ffmpegが失敗したら、stderrの末尾を表示して非0で終了

## 品質・検証
- 区間計算（無音区間 → 削除範囲 → 残す区間）は、副作用のない純粋なメソッドとして分離し、minitestでテストを書く
  （先頭無音・末尾無音・短すぎて削除されないケースを含める）
- ffmpegの `lavfi`（sine と anullsrc）でテスト用のwavを生成して、エンドツーエンドで動作確認する手順を README.md に書く
- README.md には使い方と実行例を簡潔に載せる
- コメントは日本語で書く

まず実装方針を短く提示してから、実装に着手してください。
